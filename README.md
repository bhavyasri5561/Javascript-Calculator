# My Calculator 🧮

A simple, interactive calculator built using **HTML, CSS, and JavaScript**.

## Features
- Addition, subtraction, multiplication, and division
- Percentage calculation
- Positive and negative number toggle
- Clear and delete buttons
- Keyboard support
- Responsive design for desktop and mobile
- Modern user interface with smooth animations

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Project Structure
- `index.html` — Calculator structure
- `style.css` — Styling and layout
- `script.js` — Calculator functionality

## Purpose
This project was created to practice frontend web development, DOM manipulation, event handling, and JavaScript programming.
